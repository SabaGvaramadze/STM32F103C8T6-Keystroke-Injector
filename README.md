STM32 USB Keystroke Injector

A DIY USB HID injection tool built with an STM32F103C8T6 and a hand-soldered SD card reader.

This project runs custom C firmware on an STM32 "Blue Pill" to emulate a USB keyboard, reading payload scripts over SPI from a wired microSD card.
